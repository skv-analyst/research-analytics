Обращение к API

Все обращения к API производятся по адресу:

http://api.duma.gov.ru/api/

Обращаться к API можно как с веб-сайта, так и из приложения. Во всех запросах требуется указание:

  • API-ключа для веб-сайтов;
  • API-ключа и APP-ключа для приложений.

Обращение с веб-сайта

Данный тип запросов используется при обращении к API со страниц веб-сайтов. При обращении системой проверяется заголовок запроса REFERER на соответствие домена веб-сайта домену, указанному в заявке на получение ключа.

Обращения с веб-сайта имеют следующий формат:

http://api.duma.gov.ru/api/:token/:request.:format?param1=1&param2=2

где

  • :token — значение API-ключа;
  • :request — вид запроса к API (cписок доступных запросов вы можете посмотреть в справочнике API);
  • :format — формат получения данных;
  • param1, param2 — параметры доступные для конкретного вида запроса.

Обращение из приложения

Обращения из приложения имеют следующий формат:

http://api.duma.gov.ru/api/:token/:request.:format?app_token=:app_token&param1=1&param2=2

где

  • :token — значение API-ключа;
  • :app_token — значение APP-ключа;
  • :request — вид запроса к API (cписок доступных запросов вы можете посмотреть в справочнике API);
  • :format — формат получения данных;
  • param1, param2 — параметры доступные для конкретного вида запроса.

Ограничения

В настоящий момент установлено ограничение в 50000 обращений в сутки для одного API-ключа. Вы можете отправить запрос на изменение ограничения по адресу webmaster@duma.gov.ru с информацией о сайте/приложении и причинах, требующих увеличения лимита.
