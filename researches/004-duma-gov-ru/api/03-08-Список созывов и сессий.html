Список созывов и сессий

Выводит список созывов и сессий

Запрос

http://api.duma.gov.ru/api/:token/periods.xml  
http://api.duma.gov.ru/api/:token/periods.json

Параметры

Отсутствуют

Результат

        <endDate>2007-12-23 00:00:00</endDate>

Описание формата ответа

XML

  • result — результат выполнения запроса
    • period — созыв
      • id — идентификатор созыва
      • name — название созыва
      • startDate — дата начала созыва
      • endDate — дата завершения созыва
      • session — сессия работы ГД. Объект созыва включает перечень сессий, проходивших в рамках данного созыва, которые состоят из следующих полей:
        • id — идентификатор сессии
        • name — название сессии
        • startDate — дата начала сессии
        • endDate — дата завершения сессии

JSON

Результат представляет собой массив объектов, каждый из которых является созывом:

  • id — идентификатор созыва
  • name — название созыва
  • startDate — дата начала созыва
  • endDate — дата завершения созыва
  • sessions — массив объектов, каждый из которых представляет сессиюЭлементы массива sessions состоят из следующих полей:
    • id — идентификатор сессии
    • name — название сессии
    • startDate — дата начала сессии
    • endDate — дата завершения сессии
