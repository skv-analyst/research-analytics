Список региональных органов власти

Выводит список региональных органов власти

Запрос

http://api.duma.gov.ru/api/:token/regional-organs.xml  
http://api.duma.gov.ru/api/:token/regional-organs.json

Параметры

  • current — позволяет получить список региональных органов власти, действующих (значения 1, true) или не действующих (значения 0, false) в данный момент.

Пример запроса

http://api.duma.gov.ru/api/:token/regional-organs.json?current=1

Описание формата ответа

XML

  • result — результат выполнения запроса
    • regionalOrgan — региональный орган власти
      • id — идентификатор регионального органа власти
      • name — имя регионального органа власти
      • isCurrent — региональный орган власти действует в настоящее время
      • startDate — дата начала полномочий регионального органа власти
      • stopDate — дата конца полномочий регионального органа власти

JSON

Результат представляет собой массив объектов, каждый из которых является региональным органом власти:

  • id — идентификатор регионального органа власти
  • name — имя регионального органа власти
  • isCurrent — региональный орган власти действует в настоящее время
  • startDate — дата начала полномочий регионального органа власти
  • stopDate — дата конца полномочий регионального органа власти
