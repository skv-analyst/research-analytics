Вопросы заседаний государственной думы

Запрос выводит список вопросов повестки дня заседаний Государственной Думы.

Запрос

http://api.duma.gov.ru/api/:token/questions.xml
http://api.duma.gov.ru/api/:token/questions.json

Параметры

  • dateFrom - минимальная дата заседания
  • dateTo - максимальная дата заседания
  • name - название вопроса
  • page — номер запрашиваемой страницы результатов, по умолчанию равно 1
  • limit — количество результатов на странице, допустимые значения: 5, 10, 20 (по умолчанию)

Пример запроса

http://api.duma.gov.ru/api/:token/questions.xml?limit=5&dateFrom=2013-01-01&page=2&name=образование

Описание формата ответа

XML

  • result — результат выполнения запроса
    • name - формулировка вопроса
    • pageSize - размер страницы
    • page - номер текущей страницы
    • totalCount - общее число вопросов
    • question - вопрос
    • name - название вопроса
    • datez - дата заседания
    • kodz - код заседания
    • kodvopr - код вопроса
    • nbegin - строка начала вопроса в стенограмме
    • nend - строка конца вопроса в стенограмме

JSON

Результат представляет собой объект, отражающий сведения о стенограммах проекта постановления:

  • name - формулировка вопроса
  • pageSize - размер страницы
  • page - номер текущей страницы
  • totalCount - общее число вопросов
  • questions - массив объектов, отражающих сведения о вопросах:
    • name - название вопроса
    • datez - дата заседания
    • kodz - код заседания
    • kodvopr - код вопроса
    • nbegin - строка начала вопроса в стенограмме
    • nend - строка конца вопроса в стенограмме
