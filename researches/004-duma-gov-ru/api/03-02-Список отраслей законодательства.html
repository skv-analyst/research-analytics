Список отраслей законодательства

Выводит список отраслей законодательства.

Запрос

http://api.duma.gov.ru/api/:token/classes.xml  
http://api.duma.gov.ru/api/:token/classes.json

Параметры

Отсутствуют

Результат

XML

<?xml version="1.0" ?>  
<result>  
    <class>  
        <id>68252</id>  
        <name>Безопасность и охрана правопорядка</name>  
    </class>  
    <class>  
        <id>68246</id>  
        <name>Внешнеэкономическая деятельность. Таможенное дело</name>  
    </class>  
    <class>  
        <id>68222</id>  
        <name>Гражданское право</name>  
    </class>  
    <class>  
        <id>68689</id>  
        <name>Жилище</name>  
    </class>  
</result>

JSON

[{  
    "id":68252,  
    "name":"Безопасность и охрана правопорядка"  
},{  
    "id":68246,  
    "name":"Внешнеэкономическая деятельность. Таможенное дело"  
},{  
    "id":68222,  
    "name":"Гражданское право"  
},{  
    "id":68689,  
    "name":"Жилище"  
}]

Описание формата ответа:

XML

  • result — результат выполнения запроса
    • class — отрасль законодательства
      • id — идентификатор отрасли законодательства
      • name — имя отрасли законодательства

JSON

Результат представляет собой массив объектов, каждый из которых представляет отрасль законодательства:

  • id — идентификатор отрасли законодательства
  • name — имя отрасли законодательства
