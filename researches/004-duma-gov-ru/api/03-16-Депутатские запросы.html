Депутатские запросы

Запрос выводит список депутатских запросов.

Запрос

http://api.duma.gov.ru/api/:token/requests.xml
http://api.duma.gov.ru/api/:token/requests.json

Параметры

Отсутствуют.

Пример запроса

http://api.duma.gov.ru/api/:token/requests.xml

Описание формата ответа

XML

  • result — результат выполнения запроса
    • request — результат законодательной деятельности
    • requestId — идентификатор запроса
    • initiator — инициатор
    • requestDate — дата запроса
    • name — название запроса
    • controlDate — контольная дата
    • signedDate — дата подписания
    • documentNumber — номер документа
    • resolution — номер постановления
    • answer — ответ на запроса
    • signedBy - подписавший депутатский запрос
      • id - идентификатор
      • name - название
    • addressee - адресат депутатского запроса
      • id - идентификатор
      • name - название

JSON

Результат представляет собой массив объектов, отражающих депутаткие запроса даятельности:

  • requestId — идентификатор запроса
  • initiator — инициатор
  • requestDate — дата запроса
  • name — название запроса
  • controlDate — контольная дата
  • signedDate — дата подписания
  • documentNumber — номер документа
  • resolution — номер постановления
  • answer — ответ на запроса
  • signedBy - объект, отражающий подписавшего депутатский запрос:
    • id - идентификатор
    • name - название
  • addressee - объект, отражающий адресата депутатского запроса:
    • id - идентификатор
    • name - название
