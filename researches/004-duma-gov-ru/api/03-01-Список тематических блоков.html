Список тематических блоков

Выводит список тематических блоков.

Запрос

http://api.duma.gov.ru/api/:token/topics.xml
http://api.duma.gov.ru/api/:token/topics.json

Описание формата ответа

XML

  • result — результат выполнения запроса
    • topic — тематический блок
      • id — идентификатор тематического блока
      • name — имя тематического блока

JSON

Результат представляет собой массив объектов, каждый из которых представляет тематический блок:

  • id — идентификатор тематического блока
  • name — имя тематического блока
