Справочник по API

Справочники

Помимо основного запроса предоставляется набор вспомогательных запросов для получения данных из справочников.

Тематические блоки

Набор тематик, между которыми распределяются законопроекты.

Примеры: Бюджетное, налоговое, финансовое законодательство, Социальная политика

Отрасли законодательства

Сферы жизни и отрасли, с которым относятся законопроекты.

Примеры: Гражданское право, Информация и информатизация

Стадии рассмотрения

Стадия рассмотрения законопроекта. Неотъемлемо связана с инстанцией рассмотрения. Определенные стадии разбиваются на фазы рассмотрения.

Примеры: Регистрация законопроекта в Управлении документационного обеспечения, Рассмотрение законопроекта во втором чтении

Инстанции рассмотрения

Государственный орган либо подразделение государственного органа, которое в данный момент производит рассмотрение законопроекта.

Примеры: ГД (Пленарное заседание), Президент РФ, Совет Федерации, Секретариат Председателя ГД

Федеральные органы власти

Справочник федеральных органов власти.

Примеры: Высший Арбитражный Суд РФ, Президент РФ, Совет Федерации РФ

Региональные органы власти

Справочник региональных органов власти.

Примеры: Алтайское краевое Законодательное Собрание, Архангельское областное Собрание депутатов

Комитеты

Справочник комитетов Государственной Думы, функционирующих за все время работы Государственной Думы.

Примеры: Комитет ГД по бюджету, налогам, банкам и финансам, Комитет ГД по безопасности

Созывы и сессии

Перечень созывов и сессий в рамках созывов Государственной Думы.
