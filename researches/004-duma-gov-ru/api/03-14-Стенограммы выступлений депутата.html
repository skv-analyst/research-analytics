Стенограммы выступлений депутата

Запрос выводит стенограммы выступлений конкретного депутата.

Запрос

http://api.duma.gov.ru/api/:token/transcriptDeputy/:deputy.xml
http://api.duma.gov.ru/api/:token/transcriptDeputy/:deputy.json

Параметры

  • deputy - код депутата
  • dateFrom - минимальная дата заседания
  • dateTo - максимальная дата заседания
  • name - название вопроса
  • page — номер запрашиваемой страницы результатов, по умолчанию равно 1
  • limit — количество результатов на странице, допустимые значения: 5, 10, 20 (по умолчанию)

Пример запроса

http://api.duma.gov.ru/api/:token/transcriptDeputy/99100142.xml?limit=5&page=2&dateFrom=2013-01-01

Описание формата ответа

XML

  • result — результат выполнения запроса
    • name - ФИО депутата
    • pageSize - размер страницы
    • page - номер текущей страницы
    • totalCount - общее число вопросов
    • meeting - заседание
    • date - дата заседания
    • number - номер заседания
    • maxNumber - число строк в стенограмме
    • question - вопрос рассмотрения
      • name - называние вопроса
      • stage - стадия рассмотрения
      • part - фрагмент стенограммы
      • startLine - номер строки начала фрагмента
      • endLine - номер строки конца фрагмента
      • line - строка стенограммы
      • vote - голосование
        • line - номер строки стенограммы
        • date - дата голосования

JSON

Результат представляет собой объект, отражающий сведения о стенограммах выступлений депутата:

  • name - ФИО депутата
  • pageSize - размер страницы
  • page - номер текущей страницы
  • totalCount - общее число вопросов
  • meetings - массив объектов, отражающих сведения о заседаниях:
    • date - дата заседания
    • number - номер заседания
    • maxNumber - число строк в стенограмме
    • questions - массив объектов, отражающих сведения о вопросах рассмотрения:
    • name - называние вопроса
    • stage - стадия рассмотрения
    • parts - массив объектов, отражающих сведения о фрагментах стенограммы:
      • startLine - номер строки начала фрагмента
      • endLine - номер строки конца фрагмента
      • lines - строки стенограммы
      • votes - массив объектов, отражающих сведения о голосованиях:
      • line - номер строки стенограммы
      • date - дата голосования
