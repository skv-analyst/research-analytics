Сведения о голосовании

Запрос выводит сведения о конкретном открытом голосовании Государственной Думы.

Запрос

http://api.duma.gov.ru/api/:token/vote/:id.xml
http://api.duma.gov.ru/api/:token/vote/:id.json

Параметры

  • id - идентификатор голосования

Пример запроса

http://api.duma.gov.ru/api/:token/vote/80988.xml

Описание формата ответа

XML

  • result — результат выполнения запроса
    • date - дата и время голосования
    • subject - тема голосования
    • resolution - результат голосования (true - принято, false - не принято)
    • for - число депутатов, проголосовавших "за"
    • against - число депутатов, проголосовавших "против"
    • abstain - число депутатов, проголосовавших "воздержался"
    • absent - число непроголосовавших депутатов
    • transcriptLink - ссылка на стенограмму голосования
    • resultsByFaction - результаты голосования фракции
    • code - код фракции
    • total - общее число депутатов во фракции
    • for - число депутатов, проголосовавших "за"
    • against - число депутатов, проголосовавших "против"
    • abstain - число депутатов, проголосовавших "воздержался"
    • absent - число непроголосовавших депутатов
    • name - название фракции
    • abbr - аббревиатура фракции
    • resultsByDeputy - результаты голосования депутата
    • code - код депутата
    • result - результат голсования депутата (for - "за", against - "против", abstain - "воздержался", absent - не голосовал)
    • factionCode - код фракции депутата
    • family - фамилия депутата
    • name - имя депутата
    • patronymic - отчество депутата

JSON

Результат представляет собой объект, содержащий сведения о голосовании:

  • date - дата и время голосования
  • subject - тема голосования
  • resolution - результат голосования (true - принято, false - не принято)
  • for - число депутатов, проголосовавших "за"
  • against - число депутатов, проголосовавших "против"
  • abstain - число депутатов, проголосовавших "воздержался"
  • absent - число непроголосовавших депутатов
  • transcriptLink - ссылка на стенограмму голосования
  • resultsByFaction - массив объектов, отражающих результаты голосования фракции:
    • code - код фракции
    • total - общее число депутатов во фракции
    • for - число депутатов, проголосовавших "за"
    • against - число депутатов, проголосовавших "против"
    • abstain - число депутатов, проголосовавших "воздержался"
    • absent - число непроголосовавших депутатов
    • name - название фракции
    • abbr - аббревиатура фракции
  • resultsByDeputy - массив объектов, отражающих результаты голосования депутата:
    • code - код депутата
    • result - результат голсования депутата (for - "за", against - "против", abstain - "воздержался", absent - не голосовал)
    • factionCode - код фракции депутата
    • family - фамилия депутата
    • name - имя депутата
    • patronymic - отчество депутата
