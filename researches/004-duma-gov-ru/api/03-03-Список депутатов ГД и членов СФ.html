Список депутатов ГД и членов СФ

Выводит список депутатов Государственной Думы и членов Совета Федерации.

Запрос

http://api.duma.gov.ru/api/:token/deputies.xml  
http://api.duma.gov.ru/api/:token/deputies.json

Параметры

  • begin — начало ФИО депутата ГД или члена СФ, может быть многобуквенным;
  • position — тип персоналии, может принимать значения «Депутат ГД» и «Член СФ»;
  • current — позволяет выбрать депутатов ГД и членов СФ, которые входят только в текущий созыв. Разрешенные значения: 1, true, 0, false.

Примеры запросов

http://api.duma.gov.ru/api/:token/deputies.json?current=1&position=Депутат%20ГД  
http://api.duma.gov.ru/api/:token/deputies.xml?begin=А

Описание формата ответа

XML

  • result — результат выполнения запроса
    • deputy — депутат ГД или член СФ
      • id — идентификатор депутата ГД или члена СФ
      • name — ФИО
      • position — должность («Депутат ГД» или «Член СФ»)
      • isCurrent — депутат ГД или член СФ в данной должности на данный момент

JSON

Результат представляет собой массив объектов, каждый из которых представляет депутата ГД или члена СФ:

  • id — идентификатор депутата ГД или члена СФ
  • name — ФИО
  • position — должность («Депутат ГД» или «Член СФ»)
  • isCurrent — депутат ГД или член СФ в данной должности на данный момент
