Список федеральных органов власти

Выводит список федеральных органов власти.

Запрос

http://api.duma.gov.ru/api/:token/federal-organs.xml  
http://api.duma.gov.ru/api/:token/federal-organs.json

Параметры

  • current — позволяет получить список федеральных органов власти, действующих (значения 1, true) или не действующих (значения 0, false) в данный момент.

Пример запроса

http://api.duma.gov.ru/api/:token/federal-organs.json?current=false

</result>

Описание формата

XML

  • result — результат выполнения запроса
    • federalOrgan — федеральный орган власти
      • id — идентификатор федерального органа власти
      • name — имя федерального органа власти
      • isCurrent — федеральный орган власти действует в настоящее время
      • startDate — дата начала полномочий федерального органа власти
      • stopDate — дата конца полномочий федерального органа власти

JSON

Результат представляет собой массив объектов, каждый из которых является федеральным органом власти:

  • id — идентификатор федерального органа власти
  • name — имя федерального органа власти
  • isCurrent — федеральный орган власти действует в настоящее время
  • startDate — дата начала полномочий федерального органа власти
  • stopDate — дата конца полномочий федерального органа власти
