Стенограмма рассмотрения вопроса

Запрос выводит стенограмму рассмотрения заданного вопроса повестки дня заседания Государственной Думы.

Запрос

http://api.duma.gov.ru/api/:token/transcriptQuestion/:kodz/:kodvopr.xml
http://api.duma.gov.ru/api/:token/transcriptQuestion/:kodz/:kodvopr.json

Параметры

  • kodz - код заседания
  • kodvopr - код вопроса

Пример запроса

http://api.duma.gov.ru/api/:token/transcriptQuestion/80/13.xml

Описание формата ответа

XML

  • result — результат выполнения запроса
    • meeting - заседание
    • date - дата заседания
    • number - номер заседания
    • maxNumber - число строк в стенограмме
    • question - вопрос рассмотрения
      • name - называние вопроса
      • stage - стадия рассмотрения
      • part - фрагмент стенограммы
      • startLine - номер строки начала фрагмента
      • endLine - номер строки конца фрагмента
      • line - строка стенограммы
      • vote - голосование
        • line - номер строки стенограммы
        • date - дата голосования

JSON

Результат представляет собой объект, отражающий сведения о стенограмме рассмотрения вопроса:

  • meetings - массив объектов, отражающих сведения о заседаниях:
    • date - дата заседания
    • number - номер заседания
    • maxNumber - число строк в стенограмме
    • questions - массив объектов, отражающих сведения о вопросах рассмотрения:
    • name - называние вопроса
    • stage - стадия рассмотрения
    • parts - массив объектов, отражающих сведения о фрагментах стенограммы:
      • startLine - номер строки начала фрагмента
      • endLine - номер строки конца фрагмента
      • lines - строки стенограммы
      • votes - массив объектов, отражающих сведения о голосованиях:
      • line - номер строки стенограммы
      • date - дата голосования
