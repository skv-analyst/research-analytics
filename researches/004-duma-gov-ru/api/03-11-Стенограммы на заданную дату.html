Стенограммы на заданную дату

Запрос выводит полный текст стенограмм на заданную дату.

Запрос

http://api.duma.gov.ru/api/:token/transcriptFull/:date.xml
http://api.duma.gov.ru/api/:token/transcriptFull/:date.json

Параметры

  • date — дата заседания.

Пример запроса

http://api.duma.gov.ru/api/:token/transcriptFull/2013-05-14.xml

Описание формата ответа

XML

  • result — результат выполнения запроса
    • date - дата заседания
    • meeting - заседание
    • date - дата заседания
    • number - номер заседания
    • line - строка стенограммы
    • vote - голосование
      • line - номер строки стенограммы
      • date - дата голосования

JSON

Результат представляет собой объект, отражающий сведения о стенограммах на заданную дату:

  • number - номер проекта постановления
  • meetings - массив объектов, отражающих сведения о заседаниях:
    • date - дата заседания
    • number - номер заседания
    • lines - строки стенограммы
    • votes - массив объектов, отражающих сведения о голосованиях:
    • line - номер строки стенограммы
    • date - дата голосования
